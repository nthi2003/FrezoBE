## Thêm khách

![Hàng thao tác — **Thêm khách hàng**](/docs-assets/eu/cta-row-actions.png)

1. **CRM & Khách hàng** → **Quản Lý Khách Hàng** → **Thêm khách hàng**
2. Ô **Avatar** (tuỳ chọn): kéo-thả hoặc chọn JPG/PNG/WebP (≤ 5MB)
3. Điền mẫu rồi **Thêm mới**:

| Ô | Data mẫu |
|---|----------|
| **Tên khách hàng** | *Công ty TNHH ABC Việt Nam* |
| **Số điện thoại** | *0912345001* |
| **Email** | *contact@abc.vn* |
| **Địa chỉ** | *Tầng 5, Toà Keangnam, Hà Nội* |
| **Mã số thuế** | *0100223344* |

**Kết quả:** Dòng mới; cột **Khách hàng** hiện ảnh (hoặc chữ cái nếu chưa upload).

---

## Đổi avatar (ba chỗ)

| Chỗ | Cách |
|-----|------|
| Form **Thêm** / **Cập nhật** | Ô **Avatar** — kéo-thả / chọn file |
| **Xem nhanh** (icon mắt) | Icon **máy ảnh** trên avatar → chọn ảnh |
| Hồ sơ **360°** | Avatar đầu trang → icon **máy ảnh** → upload |

Toast **Đã cập nhật avatar** → ảnh mới trên list / xem nhanh / 360°.

## Hồ sơ 360° & Cơ hội bán

![Hub tài liệu — guide Cơ hội bán](/docs-assets/eu/docs-hub-list.png)

1. Dòng khách → icon **Xem 360°**
2. Đầu trang: avatar · KPI doanh thu / cơ hội đang mở
3. Tab **Cơ hội bán** · **Hoá đơn** — CTA **Cơ hội** nhảy sang phễu bán hàng

Không dùng chữ tiếng Anh *Deal* trên màn — chỉ **Cơ hội bán**.

---

## Lỗi thường gặp

- Upload không xong → file > 5MB hoặc sai định dạng
- Không thấy **Thêm** / máy ảnh → chưa quyền — nhờ Admin
