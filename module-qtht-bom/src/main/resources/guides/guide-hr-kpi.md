# KPI và OKR

Chu kỳ mục tiêu — đặt, theo dõi, đánh giá, cập nhật hồ sơ.

---

## Bốn bước

1. **Đặt mục tiêu KPI/OKR** — Đầu kỳ, thống nhất với quản lý.
2. **Theo dõi tiến độ giữa kỳ** — Check-in định kỳ, cập nhật % Key Results.
3. **Đánh giá cuối kỳ** — Tự đánh giá + quản lý đánh giá:
   - **Đạt/vượt** → xét thưởng, thăng tiến
   - **Chưa đạt** → lập kế hoạch đào tạo
4. **Cập nhật hồ sơ nhân viên** — Lộ trình phát triển tiếp theo.

---

## Trên Frezo

- **OKR** — tạo mục tiêu + Key Results theo kỳ (2026-H1…)
- **Đánh giá hiệu suất** — self score → manager score
- Cập nhật ghi chú trên **Quản Lý Nhân Viên**
